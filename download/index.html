ПИКСЕЛЬНЫЕ МАСКИ LED-ЭКРАНОВ И ТЗ

Mac

Intel, macOS 10.14 Mojave и новее; на M1/M2/M3 работает через Rosetta. Первый запуск: правый клик по приложению → «Открыть» → «Открыть». Перетащите приложение в «Программы» — тогда оно сможет обновляться само.

Windows

Windows 10/11, 64-bit, нужен Microsoft Edge WebView2 (обычно уже есть в системе). Если появится синее окно SmartScreen: «Подробнее» → «Выполнить в любом случае» — только при первой установке, обновления приходят изнутри программы.

Скачать для Windows

Android

Android 10 и новее. Откройте скачанный файл на телефоне и разрешите установку из этого источника. Файлы сохраняются в «Загрузки/LED Mask».

Скачать APK

iPhone, iPad и любой браузер

Без установки. В Safari: «Поделиться» → «На экран Домой» — появится иконка, как у приложения.

Открыть веб-версию

Версия 2.0.7. Программы на Mac, Windows и Android сами проверяют обновления и ставят их без браузера (кнопка «Проверить обновления» внизу). Проекты .ledmask открываются во всех версиях. ТЗ сохраняется папкой: PPTX по шаблону Resolume или D3, такой же PDF и PNG каждой маски.
